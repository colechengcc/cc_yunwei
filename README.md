## 使用方法

### 1. 导入配置
将 `config.yaml` 导入到您的 Clash 客户端中：
- Clash for Windows: 将文件放入 `%USERPROFILE%\.config\clash\` 目录
- ClashX (macOS): 配置 → 导入配置文件
- Clash for Android: 配置 → 从文件导入

### 2. 选择节点
打开 Clash Dashboard (http://localhost:9090/ui)：
- 点击 "Proxy" 代理组
- 选择 "自动选择" 让系统自动测速选择最快节点
- 或直接选择任意节点进行手动连接
- 也可以使用地区分组快速筛选节点

### 3. 查看节点延迟
- 在 Dashboard 中可以看到每个节点的延迟
- 点击闪电图标可以手动测速

### 4. 切换节点
- 随时在 Dashboard 中切换不同的节点
- 地区分组让您快速找到需要的节点
- 流媒体解锁节点适合观看特定地区内容
- AI 标记的节点适合访问 AI 服务

1. **端口变化**: 
   - 混合端口从 7890 改为 9001
   - 如有程序使用旧端口，需要更新

2. **DNS 端口**: 
   - Clash DNS 监听在 1053
   - 可在系统网络设置中配置

3. **内网访问**:
   - 石墨文档等内网域名会自动使用内网 DNS（192.168.222.72/73/71）

## 故障排查

### 无法连接
- 检查端口 9001 是否被占用
- 确认节点信息是否正确
- 尝试切换不同节点

### DNS 解析失败
- 确认 DNS 端口 1053 未被占用
- 检查防火墙设置
- 查看 Clash 日志

### 内网域名无法访问
- 确认内网 DNS（192.168.222.72/73/71）可达
- 检查 nameserver-policy 配置
- 验证 respect-rules 已启用

如有问题，请查看 Clash 日志（log-level: debug）获取详细信息。
